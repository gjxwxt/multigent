# Agent documentation

This directory preserves only the state needed to resume active work.

Read order:

1. `state/feature_list.json` for the machine-readable feature summary.
2. `state/progress.md` for the verified current state.
3. `handoffs/current.md` before taking over unfinished work.
4. A decision or evidence record only when its feature is in scope.

Live Git state, tests, and API responses override these summaries. Do not put credentials, deployment secrets, or unverified conclusions here.
