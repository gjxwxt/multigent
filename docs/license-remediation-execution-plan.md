## 0. 执行原则（从 v3 红线推导的操作纪律）

1. **验收确定性**：每个批次有机器可验的验收判据（blame 上游行=0 / 测试绿 / 依赖闭包扫描通过），不靠"看着对"。
2. **审计脚本一等公民**：判据纪律（上游行>0 判据 + 依赖闭包必查）固化为 `tools/license-audit/`（见 B1），每次平移后自动跑，脚本红了批次不算完成。
3. **STOP 点显式化**：需要人裁决的地方在批次里标 `⏸ STOP`，执行到点必须停下等输入，绝不自主越过。夜间自主执行只跑无 STOP 点的批次。
4. **批次可回滚**：一个批次 = 一组提交（或新仓一组 commit），失败回滚不连带。
5. **新仓 git 卫生**：新仓从第一个 commit 起作者口径纯净；每批次 tag 可追溯；`git log` 无上游 commit 是永久不变量。

## 1. 批次总览（依赖序，非时序）

```
S0 存证收尾 ──► B1 审计工具 ──┬─► B3 存储原型 ──┐
                             │                ├─► C1 净土平移 ─► C2 实体重定义 ─► D 窄接口倒置 ─► E 切片验证 ─► F 前端回收 ─► G 切换
                             └─► B2 端点底稿 ──┴─► ⏸ 裁剪清单裁决（STOP）
A1 数据迁移决策（⏸ STOP，可与全部并行）
A2 interim 只读降级（⏸ STOP 后执行，最紧急）
```

- **S/A/B 全部无前置依赖**，其中 B2/B3 互相独立可并行（v3 §12 原序保留）。
- **C 之后串行**：C1 → C2 → D → E → F → G，每步验收过闸才进下一步。

## 4. B 批 — 两个前置（并行，产出真实数字）

### B1 审计工具 `tools/license-audit/`（机械，可夜间执行）

- `blame-authors.go`：逐文件 blame 分作者统计（gaojiaxiang / chenhg5 / root / chicken / 其他），输出 JSON。
- `closure-scan.go`：包级依赖闭包扫描，任一路径触达上游行>0 的包即标红（v3 §3 判据纪律第 2 条的自动化）。
- `verify-clean.go`：给定文件清单，验 `blame 上游行 = 0`（各平移批次的验收器）。
- 测试：用已知污染的 internal/db（45.8%）与已知干净的 projecttemplate 做对拍。
- **验收**：三个工具跑通 + 对拍测试绿 + S0.2/S0.3 产出落盘。

### B2 端点交叉底稿（机械 + 人裁决，机械部分可夜间执行）

- 脚本交叉 475 个注册端点 vs 前端实际调用 → 产出四档底稿：零调用 / 仅废弃页面调用 / 多页面共用 / 平台内部调用（health、WS 回调等）。
- WebSocket 面（agent_channel_ws + events）单列——它是上游最集中区，不是 REST 端点（v3 §7.2）。
- **⏸ STOP**：底稿出来了不等于裁剪清单定了——130 项逐一保留/延后/废弃是产品裁决，夜间只产底稿。

### B3 存储原型（核心工程，可夜间执行——这是替换估算是唯一途径）

- 按阶段 0 门面清单（v3 §4）实现 `internal/store/kvfacade`：KV CRUD + 修订守卫 + claim 语义（CommitRecordWritesGuarded/Tx 变体）+ workspace 两方法 ≈ 800-1,200 行。
- RunRepository 最小用例：workflow 实测 20+ 方法面中最薄的走通切片（transition + membership + worker 三类）。
- 并发边界测试：租约/fencing/重入（CommitTransitionGuarded 语义按 v3 §6 第 2 条：claim 持有者校验批量事务，不是 revision 乐观锁）。
- **验收**：原型测试全绿 + **实测行数/复杂度数字替换 §9 表**——数字出来后工期才有意义。

## 9. 夜间自主执行边界（给 overnight-runner 的授权范围）

**可以自主跑**：S0.2-S0.4（B1 落地后）、B1 全部、B2 机械部分、B3 全部、C1 前两包平移。
**停在 STOP 点等裁决**：A1/A2、B2 底稿后的裁剪裁决、D 批接口评审、C2 schema 定稿。
**绝不做**：push 远端、动 VM 部署、删改既有测试断言、任何 `git push --force`。
每批次完成 = 实现 + 自测 + commit（feature 分支 `license-remediation/*`）+ HANDOFF 追加一行进度。

## 10. 明确不做（沿用 v3 §11 + 执行增补）

改名式重写 / 隔离规避 / 同步上游 / 换 LICENSE / 无裁剪清单砍功能 / 无等价基线切换 / per-file 结论外推闭包 / 口径未冻结的数字用于排期；执行增补：**夜间自主执行不裁决任何 STOP 项**。
